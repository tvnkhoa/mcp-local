## MCP-ISSUE-078 — the `bin` path segment dropped Node CLI source (git now decides)

- **Status:** ✅ FIXED 2026-10-20 (release F; finding from release C).
- **Scenario:** `EXCLUDED_PATH_SEGMENTS` (and the glob ignore list) excluded every file under any `bin/` directory, so wec.aria's tracked `packages/dep-lint/bin/depcruise-guarded.mjs` was never indexed. `bin/` is where a Node package keeps its CLI entry; `build/`, `out/`, `target/` hold scripts as often as output.
- **Fix:** in a git repo (MCP-ISSUE-070 already makes git's ignore rules the authority) the build-named segments `bin`, `obj`, `build`, `out`, `target` defer to git: a file under one that git lists (tracked, or untracked and not ignored) is indexed when its language is source (`typescript` / `javascript` / `vue` / `python` / `csharp` / `proto` / `css` / `html`); anything else there stays `excluded_path`. They stay in the glob ignore list — the git-cleared files are added back from `git ls-files` (`fileScan.ts`, `hasOnlyGitDeferredSegments`), so a 30 000-file `obj/` is still never walked. A dirty run's file set comes from git, so it is cleared the same way. `node_modules`, `dist`, `.git`, the vendor / IDE trees and the other segment-only names (`wwwroot`, `logs`, …) are excluded whatever git says. Outside git, or with `CODEBASE_INDEX_RESPECT_GITIGNORE=false`, the old rule stands. `search_regex(scanAll)` keeps the strict segment rule (it reads disk without git).
- **Live:** wec.aria — `packages/dep-lint/bin/depcruise-guarded.mjs` indexed as `javascript` (javascript 141 → 142; the remaining `excluded_path .js` is `packages/portal/public/theme-boot.js`). No regression on .NET: wec.communication-hub (bin/obj ignored by `backend/CommunicationHub/.gitignore`'s `[Bb]in/` / `[Oo]bj/`) indexes 551 `.cs` files = 611 tracked − 60 EF `Designer.cs`, none under `bin/` or `obj/`.
- **Guarded:** `fileFilterReleaseF.test.ts` (deferral only for git-cleared source, never for node_modules / dist, the strict form unchanged, the candidate predicate); `test:text-json-lane` (a tracked `bin/*.mjs` indexed, `bin/notes.txt` reported `excluded_path`, a gitignored `build/` file absent).
- **Not done here:** a case-variant segment (`Bin/`) is glob-ignored case-insensitively on Windows but not segment-matched, so it is not added back (unchanged behaviour).
